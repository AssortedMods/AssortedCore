# Changelog

## 1.0.0

- First release as its own mod. It used to only be part of Assorted Core
- Worlds from Assorted Core 10.x keep all of the ores, metals and gems, along with the dusts and gears of the six metals
- Deepslate peridot ore mines at the right speed with a pickaxe
- Requires Assorted Lib 4.3.0
